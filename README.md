# 🔥 WB Price Hunter

Telegram-бот для отслеживания цен на товары в интернет-магазине Wildberries.

Бот позволяет пользователю добавлять поисковые запросы и автоматически отслеживает найденные товары. При обнаружении подходящей скидки или значительного падения цены бот отправляет уведомление в Telegram.

Проект разработан на Python в учебных целях для практики работы с Telegram Bot API, Playwright, SQLite, асинхронным программированием и обработкой данных.

## 📌 Возможности

* 🔎 Поиск товаров на Wildberries по поисковым запросам
* 📊 Получение актуальных цен, базовых цен, рейтинга и количества отзывов
* 💰 Определение размера скидки
* 📉 Отслеживание изменения цены товара
* 🔔 Отправка уведомлений в Telegram при значительном снижении цены
* 👤 Поддержка нескольких пользователей
* 📝 Добавление собственных поисковых запросов
* 📋 Просмотр списка отслеживаемых запросов
* 🗑 Удаление поисковых запросов
* 💾 Сохранение истории цен в SQLite
* 📑 Сохранение и ротация логов
* ⚙️ Настройка критериев подходящих товаров

## 🛠 Технологии

* **Python 3.11**
* **Playwright** — автоматизация браузера и получение данных с Wildberries
* **python-telegram-bot** — взаимодействие с Telegram Bot API
* **SQLite** — хранение пользователей, поисковых запросов, истории цен и уведомлений
* **asyncio** — асинхронная работа приложения и периодических проверок
* **python-dotenv** — загрузка конфигурации и токена Telegram-бота из `.env`

## ⚙️ Как работает приложение

### 1. Пользователь добавляет поисковый запрос

Например:

```text
/add алмазная мозаика
```

Бот сохраняет запрос в базе данных и начинает отслеживать товары по нему.

### 2. Получение товаров

Приложение открывает страницу поиска Wildberries с помощью Playwright.

Playwright позволяет получить данные непосредственно из браузера и перехватить внутренний сетевой запрос Wildberries, который используется сайтом для загрузки каталога товаров.

Из JSON-ответа извлекаются:

* ID товара
* название
* бренд
* текущая цена
* базовая цена
* рейтинг
* количество отзывов
* размер скидки

Приложение получает до 100 товаров из одного поискового запроса.

### 3. Анализ товаров

Полученные товары проходят через систему фильтрации.

Проверяются:

```text
Минимальный рейтинг
Минимальное количество отзывов
Минимальная скидка
Минимальное падение цены
```

Настройки находятся в `settings.py`.

### 4. Сохранение истории цен

Информация о ценах сохраняется в SQLite.

При следующей проверке приложение получает последнюю сохранённую цену товара и сравнивает её с текущей.

Если цена снизилась на заданный процент, создаётся событие падения цены.

### 5. Telegram-уведомление

Если уведомление по такой цене ещё не отправлялось, пользователь получает сообщение:

```text
🔥 РЕЗКОЕ ПАДЕНИЕ ЦЕНЫ

🛍 Название товара
🔖 Бренд: ...

💰 Было: 1500 ₽
🔥 Сейчас: 1100 ₽

📉 Падение: 27%

⭐ Рейтинг: 4.9
💬 Отзывов: 500

🔗 Ссылка на товар
```

После успешной отправки уведомление сохраняется в базе данных, чтобы не отправлять одно и то же уведомление повторно.

## 🤖 Команды Telegram-бота

| Команда         | Назначение                             |
| --------------- | -------------------------------------- |
| `/start`        | Запуск бота и регистрация пользователя |
| `/id`           | Получение Telegram ID                  |
| `/add запрос`   | Добавление поискового запроса          |
| `/list`         | Просмотр отслеживаемых запросов        |
| `/remove номер` | Удаление поискового запроса            |

### Пример

```text
/add гель для бровей
```

После добавления запроса бот будет использовать его при следующих проверках.

## ⚙️ Настройки

Основные параметры находятся в `settings.py`:

```python
CHECK_INTERVAL = 900

MIN_RATING = 4.0
MIN_REVIEWS = 10
MIN_DISCOUNT = 30
MIN_PRICE_DROP = 20
```

### Значения параметров

* `CHECK_INTERVAL = 900` — проверка каждые 15 минут
* `MIN_RATING = 4.0` — рейтинг товара не ниже 4.0
* `MIN_REVIEWS = 10` — минимум 10 отзывов
* `MIN_DISCOUNT = 30` — скидка от 30%
* `MIN_PRICE_DROP = 20` — падение цены от 20%

## 🔐 Конфигурация

Для работы Telegram-бота используется файл `.env`.

Создайте его в корне проекта:

```env
BOT_TOKEN=ваш_токен_бота
```

Токен Telegram-бота является секретными данными и **не должен публиковаться в GitHub**.

Для примера конфигурации можно использовать `.env.example`:

```env
BOT_TOKEN=your_telegram_bot_token
```

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/Samurasf/WB-Price-Hunter.git
cd WB-Price-Hunter
```

### 2. Создание виртуального окружения

Windows:

```powershell
python -m venv .venv
```

Активация:

```powershell
.venv\Scripts\activate
```

После активации в терминале появится:

```text
(.venv) PS C:\...\WB-Price-Hunter>
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Установка браузера Playwright

```bash
playwright install chromium
```

### 5. Создание `.env`

Создайте в корне проекта файл `.env`:

```env
BOT_TOKEN=ваш_токен_бота
```

### 6. Запуск

Для запуска Telegram-бота:

```bash
python run_bot.py
```

Для запуска системы мониторинга цен:

```bash
python main.py
```
